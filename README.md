# My first game made using Python library

repository contains the files used to build this game at my Game Lab classes

# Content
-Iteration structure
-Functions structure
-Coordinates operations
-Game Logic

# Goal
the main goal of my Game Lab classes was to create a game in a already known type but using the University Library made for games in Python called PPlay.
the main goal of my game was to push the boxes into the right place indicated by the blue circles knowing that the box cannot be pushed against the wall.
it gets harder with each level you reach so the users have more desire to finish the challenge but also in a achievable way so they can continue playing the game.
